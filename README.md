# JobListingUI

A simple and responsive Job Listing UI built using React.js.

## Features
- Displays job openings using reusable components.
- Uses props and JavaScript arrays for dynamic rendering.
- Shows company name, job role, salary, and location.

## Tech Stack
- React.js
- JavaScript
- HTML
- CSS
- Vite

## Getting Started

```bash
git clone https://github.com/udit88609/JobListingUI.git
cd JobListingUI
npm install
npm run dev
```
